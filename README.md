# Valen

## Sobre o projeto
O Valen é um sistema web voltado à divulgação e ao aluguel de casas de praia, permitindo que os usuários conheçam as opções de hospedagem disponíveis.

## Objetivo
Desenvolver um sistema web utilizando Django, HTML e CSS, aplicando os conhecimentos de Programação para Internet.

## Tecnologias utilizadas
- Python
- Django
- HTML
- CSS
- Git e GitHub
